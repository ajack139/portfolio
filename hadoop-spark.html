Movies Project — Spark (RDD)

Implemented movie analytics queries on a MovieLens‑style dataset using PySpark RDD transformations/actions, focusing on reliable parsing and correct aggregations.

Problem

Real CSV data is messy (commas in titles, multi‑genre fields). The task was to compute accurate results without “silent” parsing errors.

Goal

Use Spark RDD APIs to answer required dataset queries and produce interpretable outputs.

What I did

  • Loaded and parsed movies.csv and ratings.csv
  • Built RDD pipelines per query (map/filter/groupByKey/reduceByKey)
  • Validated results by sampling outputs and cross‑checking counts
  • Documented approach and results

Tools & datasets

  • Apache Spark / PySpark (RDD)
  • Linux / CLI
  • movies.csv (movieId, title, genres)
  • ratings.csv (userId, movieId, rating, timestamp)

Queries implemented

Q1: Comedy movies by year (1995+)

Extracted year from titles, expanded genres, grouped results by year.

Q2: % of users with ≥1 five‑star rating

Filtered rating == 5, counted distinct users, divided by total users.

Q3: % of users with avg rating ≥ 3.5

Computed per‑user averages, then counted users meeting the threshold.
