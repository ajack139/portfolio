Movies Project — Spark (RDD)

Implemented movie analytics queries on a MovieLens-style dataset using PySpark RDD transformations/actions. Focused on reliable parsing (commas in titles, pipe-separated genres), aggregations, and interpretable outputs.

Apache Spark PySpark RDD CSV Parsing Data Aggregation Linux/CLI
← Back to Projects

Goal

Use Spark RDD APIs to answer required dataset queries (Q1–Q3) and extend the analysis with optional queries (Q4–Q5).

My role

  • Loaded and parsed movies.csv and ratings.csv
  • Built RDD pipelines per query (map/filter/groupByKey/reduceByKey)
  • Validated results using take() / printed outputs
  • Documented approach and results for submission

Datasets

  • movies.csv: movieId, title (includes year), genres
  • ratings.csv: userId, movieId, rating, timestamp

Skills demonstrated

  • Data parsing + cleaning for real CSV quirks
  • Aggregation logic and joining related datasets by IDs
  • Distributed computation mindset with Spark RDDs

Queries implemented

Q1 (Required): From 1995 onward, Comedy movies by year

Parsed movie titles to extract year, expanded pipe-separated genres, filtered to Comedy, then grouped results by year.

  • Key ops: map, filter, flatMapValues, groupByKey

Q2 (Required): % of users who gave at least one 5-star rating

Filtered ratings where rating == 5, counted distinct users who gave at least one 5, and divided by total distinct users.

  • Key ops: filter, distinct, count

Q3 (Required): % of users with average rating ≥ 3.5

Grouped ratings by user to compute per-user averages, then calculated the percentage meeting the threshold.

  • Key ops: groupByKey, average calculation, filter, count

Q4 (Optional): Per-genre average rating + number of films

Computed average rating per movie, joined ratings with movie genres, then aggregated per genre to output: (1) average rating and (2) number of films in that genre. Movies with multiple genres are counted in each genre.

  • Key ops: join by movieId, genre expansion, per-genre aggregation
