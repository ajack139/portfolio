Niner Tunes

A music app concept and interactive prototype focused on clear user flows, UI consistency, and iterative refinement through usability feedback.

← Back to Projects

Goal

Design a clean discovery‑to‑playback experience with consistent navigation and predictable interactions.

Tools

  • Figma
  • Interactive prototyping
  • Usability feedback + iteration

What I did

  • Mapped end‑to‑end user flow from discovery → playback
  • Designed reusable UI patterns for navigation and controls
  • Iterated on the prototype based on peer/instructor feedback

Usability feedback

  • Reduced steps in key flows (less tapping to reach playback)
  • Improved labels and hierarchy for quicker scanning
  • Made states more obvious (selected/playing/paused)

Demo + screenshots

Video walkthrough and interaction highlights.

Prototype snippet

A simple representation of how the main flow was structured.

// Core flow (high level)
Start → Home (discovery)
  → Search / Browse
  → Select track
  → Now Playing (play / pause / queue)
  → Library (saved + recent)
  → Back to Home

What I learned

  • Consistency is a feature: repeated patterns reduce user hesitation.
  • Small UI details (labels, spacing, states) meaningfully change perceived clarity.
  • Testing early prevents “pretty but confusing” prototypes.
